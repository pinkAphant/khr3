# `@khr3/core`

Khronos `KHR_physics_rigid_bodies` + `KHR_implicit_shapes` + `OMI_vehicle_wheel` loader, exporter, Rapier WASM assembly, and `@pinkaphant/ecctrl` vehicle rig for React Three Fiber.

## Entrypoints

- `@khr3/core` — `loadKhrGlb`, `useKhrGlb`, `exportKhrGlb`, `cloneKhrBundle`, `disposeKhrBundle`, `PhysicsWorld`, `KhrAssembly`, `KhrCollider`, `JointRegistryContext`
- `@khr3/core/vehicle` — `KhrVehicle`, `solveWheelLoads`
